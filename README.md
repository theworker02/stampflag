# stampflag

Stamp timestamps and flag durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/stampflag/

## Install / run

```bash
git clone https://github.com/theworker02/stampflag.git
cd stampflag
node src/cli.js
node --test
```
